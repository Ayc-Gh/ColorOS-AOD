# RC5 USB 验证记录

版本：1.10.0-rc5-usb / versionCode 32。设备：PHY110，Android 16，PHY110_16.0.10.500(CN01)。框架：LSPosed API 102。

## 修复

- 修正全天全景能力发布和提前隐藏，保留 ColorOS 原生淡出、唤醒及清理。
- 非超时隐藏结束可见会话并取消计时，物理 OFF 不再被通用原因字符串误拦截。
- 应用和 Hook 共用配置模型与解析器；远端刷新同步更新本地断连回退副本，离线修改待重连重试。
- 删除死代码和历史发布流程，关闭 Release DEBUG 追踪，收窄压缩保留规则。

## 验证

- 27 项单元测试通过；testDebugUnitTest、lintRelease、assembleRelease 成功。lint 为 0 错误、22 警告。
- 主页、亮度页和功能页启动检查无 AndroidRuntime 崩溃。
- 最终一分钟会话跨过整分钟刷新：58937 ms 的配额隐藏被延后，60011 ms 到期，约 1 秒原生淡出后物理 OFF。用户确认一分钟、单击阻止、双击唤醒正常。
- 关闭低光保护：真实传感器约 0.62 lux，允许原生 hideClock(reason=6)，约 0.9 秒后物理 OFF，没有延后至自定义 10 分钟上限。
- 开启低光保护：真实传感器约 2.69 lux，低光回调被阻止，保持 DOZE_SUSPEND。
- 低光为受控真实传感器对照：临时提前满足系统累计检查时间，未伪造 lux 或改变系统时间。正式包和源码没有临时探针；用户原配置恢复。

## 安装包

- arm64-v8a，APK 2446278 字节，相比 RC4 6427590 字节减少约 61.9%。
- SHA-256：`fe2e547f7159e1c1e7efaecb542ff0f85ed97b1baf597f3f256784937ca12904`。
- 手机安装包哈希与交付包相同；Release 不可调试，无 Frida、低光探针、独立常驻 Service 或 INTERNET 权限。
- 沿用本地 USB 测试签名，可覆盖本次 RC4；与旧 GitHub 发布证书不同。旧版升级遇到签名冲突时，应先备份设置再卸载旧版安装。
