# v1.10.0 正式版

2026-10-10，基于已完成实机验证的 RC5 发布；versionCode 33。运行逻辑与 RC5 相同，本次变更为版本号、长期正式签名、发布流程与文档。

## 已验证

- RC5 的 27 项单元测试、lint 和优化 Release 构建通过，GitHub CI 通过。
- PHY110 / Android 16 / PHY110_16.0.10.500(CN01)，LSPosed API 102：一分钟息屏跨整分钟刷新正常，单击防误触和双击唤醒正常。
- 真实低光传感器受控对照通过；正式代码不含临时低光探针和 Frida。
- RC5 的详细实机证据见 [RC5-validation.md](RC5-validation.md)，历史测试范围不因正式版标签扩大。

尚未完成整夜自然运行、全部显示时长组合和其他机型验证。没有实测耗电改善百分比。正式签名包尚未在手机上卸载旧模块并重新安装复测；本次不主动清除用户的模块设置。
